An anchor-tag embedding and governance system designed to give AI coding agents deterministic wayfinding across complex repositories without hallucinating file paths or breaking builds.

## Key Capabilities

1. **Anchor Embedding**: Structured, machine-readable anchor tags placed at architectural boundaries
2. **Governance & Validation**: Automated checks ensuring anchors stay synchronized with refactored symbols
3. **Agent Planning**: Enables coding agents to resolve exact entry points before editing
