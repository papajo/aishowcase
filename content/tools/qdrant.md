Qdrant is an open-source vector similarity search engine written in Rust, offering fast HNSW indexing and expressive boolean payload filtering.

## Key Strengths

- **Local-First & Cloud**: Runs as a single lightweight Docker container or managed cluster
- **Payload Filtering**: Filter on structured metadata before/during vector distance scoring
- **Binary & Scalar Quantization**: Cuts memory footprint for larger embedding collections

## Verdict

Ideal when you want low-latency vector search with full self-hosting control.
