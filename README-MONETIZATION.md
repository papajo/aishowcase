# Monetization Guide — AI Showcase

This document explains how affiliate links, featured sponsorships, and opt-in display ads work in **AI Showcase** (`https://aishowcase.qzz.io`).

---

## 1. Display Ads (Opt-In, Default OFF)

Display ads are controlled by environment variables and default to **OFF**.

### Environment Variables

| Variable | Default | Description |
|---|---|---|
| `NEXT_PUBLIC_ADS_ENABLED` | unset (`false`) | Set to `"true"` to enable `<AdSlot>` containers and the AdSense `<Script>` in `app/layout.tsx`. |
| `NEXT_PUBLIC_ADSENSE_CLIENT` | unset | Your Google AdSense publisher ID (e.g. `ca-pub-1234567890123456`). |

### How to Flip Ads On

1. In **Vercel** (Project Settings → Environment Variables) or `.env.local` for local testing:
   ```bash
   NEXT_PUBLIC_ADS_ENABLED=true
   NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-XXXXXXXXXXXXXXXX
   ```
2. Redeploy (Next.js inlines `NEXT_PUBLIC_*` variables at build time).
3. Verify `<AdSlot>` renders:
   - Below the **Featured Projects** grid on `/` (`slot="home-projects"`)
   - At the end of journal articles on `/journal/[slug]` (`slot="journal-end"`)
4. To turn ads off again, remove `NEXT_PUBLIC_ADS_ENABLED` or set it to `"false"` and redeploy.

## 2. Affiliate URLs & Sponsor Tiers

### Database Schema (`prisma/schema.prisma`)

The `Tool` model includes:
- `affiliateUrl` (`String?`, nullable): Optional partner/affiliate destination URL.
- `sponsorTier` (`SponsorTier` enum: `none` | `basic` | `featured`, default `none`).

### UI Behavior

- **Tool detail pages (`/tools/[slug]`)**:
  - When `affiliateUrl` is set, the primary CTA renders **"Try {Tool} →"** linking to `affiliateUrl` with `rel="sponsored noopener"` and `target="_blank"`.
  - When `affiliateUrl` is unset and `websiteUrl` is set, it falls back to the plain **"Visit Site"** link (`rel="noopener noreferrer"`).
- **Tools directory (`/tools`)**:
  - Tools with `sponsorTier === "featured"` display a terminal-styled **"Featured"** badge in `ToolCard`.

### How Affiliate URLs Flow Through the Pipeline

1. **PostgreSQL / Admin UI (`/admin/tools`)**:
   - Create or edit a tool via `/admin/tools` or `POST`/`PUT` `/api/admin/tools` with `affiliateUrl` and `sponsorTier`.
2. **Markdown Tools (`content/tools/*.md`)**:
   - Add `affiliateUrl` and `sponsorTier` in YAML frontmatter:
     ```yaml
     ---
     name: "Example Tool"
     websiteUrl: "https://example.com"
     affiliateUrl: "https://example.com/?ref=aishowcase"
     sponsorTier: "featured"
     ---
     ```
   - Parsed automatically by `lib/md-utils.ts`.
3. **Python Content Pipeline (`scripts/tool_schema.py`)**:
   - `ToolData` (`TypedDict`) and `format_tool_frontmatter()` define the canonical shape (`affiliateUrl`, `sponsorTier`) for any Python script generating tool entries or calling `/api/admin/tools`.

## 3. Google AdSense Application Checklist

1. **Privacy Policy**: `/privacy` is live and linked in the footer, covering `@vercel/analytics`, newsletter emails, affiliate links, and ad-network cookies.
2. **Content Readiness**: Ensure `/tools`, `/projects`, `/journal`, `/about`, `/contact`, and `/privacy` are accessible and indexed (check `/sitemap.xml` generated by `next-sitemap`).
3. **Apply in Google AdSense**:
   - Submit `https://aishowcase.qzz.io` in your AdSense account.
   - Copy your `ca-pub-...` publisher ID into `NEXT_PUBLIC_ADSENSE_CLIENT` and set `NEXT_PUBLIC_ADS_ENABLED=true`.
   - Optionally add `public/ads.txt` with your publisher record (`google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`) once AdSense provides it.
4. **Deploy & Verify**:
   - Trigger a Vercel production build so `<Script>` in `app/layout.tsx` is active for AdSense site verification.
